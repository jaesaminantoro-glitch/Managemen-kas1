# Warteg Bahariku - Sistem Pemesanan Online & Panel Admin

Aplikasi web interaktif untuk pemesanan makanan prasmanan secara online di lingkungan kerja/kantor (dilengkapi panel pengelola dapur).

## 🎯 Fitur Utama

### 🍽️ Sisi Pelanggan (Customer View)
- **Status Operasional Toko**: Informasi otomatis apakah warteg sedang Buka atau Tutup berdasarkan jam operasional harian.
- **Daftar Menu Prasmanan**: Menampilkan pilihan menu (Nasi, Sayur, Lauk/Protein, dll.) lengkap dengan harga dan indikator ketersediaan (Tersedia/Habis).
- **Keranjang Belanja Interaktif**: Tambah/kurang porsi pesanan dengan mudah dan pembaruan total harga otomatis secara *real-time*.
- **Formulir Isian Pesanan**: Memasukkan data pembeli (Nama Lengkap, Department, dan Lokasi Makan/Antar seperti Kantin, Mess, atau Kantor).
- **Cek Status Pesanan**: Fitur pengecekan status pesanan aktif secara mandiri (Diproses, Diantar, Selesai).

### 🍳 Sisi Pengelola / Admin (Admin View)
- **Dashboard Statistik**: Pemantauan cepat total pesanan masuk dan akumulasi omset harian/total.
- **Pengaturan Jam Operasional**: Mengatur jam buka dan tutup dapur secara fleksibel atau mengubah status toko secara manual (Buka/Tutup/Otomatis).
- **Manajemen Antrean Pesanan**: Pemantauan pesanan masuk secara *real-time* dengan opsi pembaruan status pengiriman (Diproses $\rightarrow$ Diantar $\rightarrow$ Selesai).
- **Rekapan Bulanan (Matriks Tanggal):** Tabel matriks rekapitulasi transaksi pelanggan per tanggal (1 sampai 31) lengkap dengan fitur *Export* ke format file CSV/Excel.
- **Manajemen Stok & Harga Menu**: Pengaturan harga satuan menu dan pengubahan status ketersediaan menu (Tersedia / Habis) secara instan.

## 📱 Teknologi yang Digunakan
- **HTML5 & JavaScript (Vanilla)**: Logika aplikasi interaktif sisi klien.
- **Tailwind CSS**: Desain antarmuka modern yang responsif untuk perangkat seluler maupun desktop.
- **FontAwesome**: Ikon pendukung visual antarmuka.
- **Google Fonts (Plus Jakarta Sans)**: Tipografi yang ramah dibaca dan modern.
