# IE-toolkit

Untuk membantu pekerjaan IE (Industrial Engineering).

## 🎯 Fitur Utama

### Time Study
- **3 Mode**: Mesin, Elemen, Siklus
- **Multi-Line & Multi-Model**: Data dipisah per Line + Model
- **Batching**: 1 LAP bisa = N unit (waktu otomatis dibagi)
- **Preinstallasi Mode**: Rekam beberapa SOP/Elemen sekaligus
- **Inline Edit**: Klik langsung kolom kuning untuk edit
- **Sync Firebase**: Real-time multi-device
- **Backup & Restore**: Export/import JSON
- **Arsip**: Simpan data per bulan
- **Export Excel & CSV**: Dengan styling otomatis

### 🤖 AI Element Balancing (BARU)
- **AI Balancing**: Saran pemindahan elemen kerja (tanpa pindah operator)
- **Precedence**: Atur ketergantungan antar elemen
- **Movable**: Tandai elemen yang boleh/tidak digeser AI
- **Auto-Precedence**: Generate precedence otomatis dari nama elemen
- **What-If Simulator**: Simulasi takt time virtual
- **History**: Bandingkan hasil run AI dari waktu ke waktu
- **Unit Test**: Validasi AI engine sebelum produksi
- **LLM Integration**: Penjelasan bahasa natural (opsional)
- **Apply with Backup**: Terapkan saran AI + backup otomatis
- **Export Report**: Excel report lengkap
